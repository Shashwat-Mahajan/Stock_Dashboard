Indian Stock Market Visualizer

Explore historical trends of Indian stock indices with interactive charts powered by clean CSV data. Built with Next.js, Chart.js, and love.

📊 Key Features

📁 CSV-Based Data

Load stock market data directly from CSV for fast, reliable access without API calls.

📈 Interactive Charts

Visualize closing index values over time with dynamic, responsive line graphs.

🏢 Company-Wise Filtering

Easily switch between different stock indices to get instant insights.

⚙️ Built with Next.js

Optimized for performance with SSR, modular styling, and easy routing.
